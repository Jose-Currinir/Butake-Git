# Seguridad

Si encuentras una vulnerabilidad, **no abras un issue público**. Usa
[«Report a vulnerability»](../../security/advisories/new) en la pestaña Security de este
repositorio (aviso privado de GitHub). Responderemos lo antes posible.

Incluye, si puedes: versión o commit, pasos para reproducir y el impacto que ves.

Butake Git nunca guarda tokens en el repositorio, en registros ni en preferencias: viven
sólo en el llavero de macOS. Git usa tu SSH Agent y tu gestor de credenciales.
